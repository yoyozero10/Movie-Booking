# UI Rules --- Quy Tắc Giao Diện

## 1. Màu Sắc (Color Scheme)

### Primary Colors (Màu Chính)

-   **Blue Primary**: `blue-500` (#3b82f6)
-   **Blue Hover**: `blue-600` (#2563eb)
-   **Blue Light**: `blue-50` (#f0f9ff), `blue-100` (#dbeafe)
-   **Blue Border**: `border-blue-500`, `border-blue-500/60`

### Success Colors (Màu Thành Công)

-   **Green Primary**: `green-500` (#22c55e)
-   **Green Hover**: `green-600` (#16a34a)
-   **Green Light**: `green-50`, `green-100`, `green-200`
-   **Green Text**: `text-green-600`

### Error/Danger Colors (Màu Lỗi)

-   **Red Primary**: `red-500` (#ef4444)
-   **Red Hover**: `red-600` (#dc2626)
-   **Red Light**: `red-50`, `red-100`, `red-200`
-   **Red Text**: `text-red-500`, `text-red-600`

### Background Colors

-   **White**: `bg-white`
-   **Backdrop**: `bg-black/50` + `backdrop-blur-sm`
-   **Semitransparent**: `bg-white/50`, `bg-white/90`
-   **Light Backgrounds**: `bg-zinc-50`, `bg-zinc-100`

### Linear Gradient Backgrounds

-   Blue -\> Purple
-   Yellow -\> Orange -\> Pink
-   Blue -\> Indigo
-   Blue -\> Indigo Light

### Background Pattern

-   Pattern size: **40px 40px**
-   Color: `rgba(224, 224, 224, 0.3)`

## 2. Typography

-   **Primary Font**: Be Vietnam Pro
-   **Mono Font**: Be Vietnam Pro (monospace)

## 3. Border, Radius, Spacing

-   Border: tránh shadow, dùng border mỏng
-   Radius: lg \> md \> sm
-   Spacing: 4, 6, 8, 12, 16, 24

## 4. Icon & Emoji

-   Dùng Lucide, Heroicons, Font Awesome
-   Không dùng emoji cho UI icon

## 5. Animation

-   Duration: 120--260ms
-   Easing: ease-out
-   Tránh animation lố

## 6. Layout & Component Structure

### Button

-   Border thay shadow
-   Subtle hover \### Card
-   Border nhẹ
-   Spacing logic
-   Heading khác body font

## 7. Anti-AI Look Summary

-   Không shadow lố
-   Không gradient spam
-   Không radius đồng nhất
-   Không Emoji icon
-   Không palette xanh--tím default
-   Font phải có personality
-   Animation tinh tế
