## 🎨 **DESIGN SYSTEM - COMPLETE**

### **Colors**
```css
Apple Blue: #007AFF (primary)
Blue Hover: #0056CC
Apple Orange: #FF9500 (premium)
Orange Hover: #FF6B00
Apple Red: #FF2D55 (danger)
Background: linear-gradient(180deg, #000 0%, #0a0a0a 50%, #1a1a1a 100%)
```

### **Glassmorphism**
```css
.apple-glass {
  background: rgba(255, 255, 255, 0.05);
  backdrop-filter: blur(40px) saturate(180%);
  border: 0.5px solid rgba(255, 255, 255, 0.1);
  box-shadow: 0 32px 64px rgba(0, 0, 0, 0.4);
}

.premium-glass {
  background: linear-gradient(135deg, rgba(255, 255, 255, 0.08), ...);
  backdrop-filter: blur(60px) saturate(200%);
  box-shadow: 0 48px 100px rgba(0, 0, 0, 0.35);
}
```

### **Seat Styles**
- **Available**: `linear-gradient(135deg, rgba(142, 142, 147, 0.3), rgba(99, 99, 102, 0.4))`
- **Selected**: `linear-gradient(135deg, #007AFF, #0056CC)` + glow
- **Occupied**: `linear-gradient(135deg, rgba(99, 99, 102, 0.6), rgba(72, 72, 74, 0.7))`
- **Premium**: `linear-gradient(135deg, #FF9500, #FF6B00)` + glow

### **Animations**
- **Duration**: 1.2s - 1.8s
- **Easing**: `cubic-bezier(0.25, 0.46, 0.45, 0.94)`
- **Types**: fadeIn, slideUp, blurIn, scaleIn, slideRight, slideLeft, float
- **Delays**: 100ms - 1400ms (stagger effects)
