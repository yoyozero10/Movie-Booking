Business Rules for Langfens English
ID
	Rule Definition
	Type of Rule
	Static or Dynamic
	Source
	BR-1
	Each exam must belong to exactly one exam category in the exam catalog.
	Fact
	Static
	Product Owner
	BR-2
	An exam can be in one of the following states: Draft, Published, Archived. Only Published exams are visible to visitors and candidates.
	Fact
	Static
	Product Owner
	BR-3
	Only Admin users can create, update, publish, or archive exams in the exam catalog.
	Constraint
	Static
	Product Owner
	BR-4
	Once an exam has at least one completed attempt, its structure (sections, questions, scoring weights) cannot be edited; a new exam version must be created instead.
	Constraint
	Static
	Academic Lead
	BR-5
	The time limit and configuration of an exam attempt are stored as part of an immutable delivery snapshot when the attempt is started.
	Fact
	Static
	System Architect
	BR-6
	A candidate can have at most one active (in-progress) attempt per exam at any given time.
	Constraint
	Dynamic
	Product Owner
	BR-7
	Exam scores are calculated as the sum of the scores of all answered questions according to the scoring rules in the delivery snapshot.
	Computation
	Dynamic
	Academic Lead
	BR-8
	Overall exam band (e.g., IELTS-like band) is computed from the total score using the band mapping table defined by the Academic Lead.
	Computation
	Dynamic
	Academic Lead
	BR-9
	Course content must be organized hierarchically as Course → Module (optional) → Lesson; progress is tracked at lesson level.
	Fact
	Static
	Product Owner
	BR-10
	A learner can enroll in and access a course only if the course is in Published state.
	Constraint
	Static
	Product Owner
	BR-11
	Course progress percentage is calculated as the number of completed mandatory lessons divided by the total number of mandatory lessons in the course, multiplied by 100 and rounded to the nearest whole percent.
	Computation
	Dynamic
	Academic Lead
	BR-12
	Each vocabulary card must belong to exactly one deck; only Published decks and cards are visible to the public and learners.
	Fact
	Static
	Product Owner
	BR-13
	A learner subscribes to a deck to add it to their personal review list; unsubscribing does not delete any historical review sessions or statistics.
	Fact
	Static
	Product Owner
	BR-14
	Only Admin or designated content creators can create, modify, or delete vocabulary decks and cards.
	Constraint
	Static
	Product Owner
	BR-15
	User email addresses must be unique across all accounts.
	Constraint
	Static
	Security Policy
	BR-16
	OTP codes for account registration and password reset consist of 6 digits and expire 10 minutes after generation.
	Constraint
	Dynamic
	Security Policy
	BR-17
	The system must limit OTP generation to at most 5 valid OTPs per user email within any rolling 1-hour period.
	Constraint
	Dynamic
	Security Policy
	BR-18
	A user account is considered verified only after the system successfully validates an OTP sent to the user’s email address.
	Fact
	Static
	Product Owner
	BR-19
	Network transmissions that contain passwords, OTPs, or personally identifiable information must use HTTPS with TLS 1.2 or higher.
	Constraint
	Static
	Security Policy
	BR-20
	Only authenticated users can start exam attempts, enroll in courses, or subscribe to vocabulary decks.
	Constraint
	Static
	Security Policy
	BR-21
	A visitor (unauthenticated user) can only browse exams, courses, lessons, and decks that are marked as Published and Public.
	Constraint
	Static
	Product Owner
	BR-22
	A user session remains valid only within the configured session timeout; after timeout, the user must log in again.
	Constraint
	Dynamic
	Security Policy
	BR-23
	Writing and speaking exam tasks are stored as part of the exam structure and included in the delivery snapshot; changes to these tasks do not affect existing attempts.
	Fact
	Static
	Academic Lead
	BR-24
	Scores or feedback for writing and speaking tasks can be recorded or updated only by users with Admin role or a role explicitly granted by the Admin for assessment.
	Constraint
	Static
	Product Owner
	BR-25
	Internal attempt services must always use the delivery snapshot associated with an attempt and must not query the live exam catalog to evaluate or re-score that attempt.
	Constraint
	Static
	System Architect
